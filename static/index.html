About

sql-coach-forge is a static-pattern SQL query coach. It runs locally, ships with ~30 anti-pattern rules, and never sends your SQL anywhere. Use it before merging a PR, after a slow EXPLAIN, or as a teaching tool when reviewing someone else's query.

  • Backend: Flask + SQLite (one file: sql_coach.sqlite3)
  • Frontend: vanilla JS + CSS, dark theme
  • Anti-patterns: 30+ regex-driven rules with severity and per-rule fixes
  • Execution plan: pseudo-step sketch, not engine EXPLAIN output
  • Refactor library: 8+ before/after diffs, triggered by the matching anti-pattern
  • Flavor hints: 11 dialects (Snowflake, BigQuery, Postgres, SQL Server, MySQL, Oracle, DuckDB, Databricks, Spark, Redshift, generic)
Built for engineers · local-first · no API keys
